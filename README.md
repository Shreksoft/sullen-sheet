# Sullen-sheet

[![Deploy to Pages](https://github.com/Shreksoft/sullen-sheet/actions/workflows/ghp-deploy.yml/badge.svg)](https://github.com/Shreksoft/sullen-sheet/actions/workflows/ghp-deploy.yml)

Приложение, которое позволяет *удобно* проверять tg proxy.

>*Удобно* - это
>нажатие кнопки в браузере → перейти в tg → увидеть работает ли прокси

## Мотивация создания:

Не копировать руками ссылки из источников и вставлять в телеграм по одной

## Возможности:

- Предоставление таблицы дефолтных ссылок с `n` ресурса
- Уродский интерфейс

## Stack:

- Ts
- Vite
- React
