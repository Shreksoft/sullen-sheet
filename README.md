# tg-proxy-list

Приложение, которое позволяет "удобно" проверять tg proxy.

>Удобное по сути - это
>нажатие кнопки в браузере → перейти в tg → увидеть работает ли прокси

## Мотивация создания: 

Не копировать руками ссылки из источников и вставлять в телеграм по одной

## Возможности `major`:

1. Предоставление таблицы дефолтных ссылок с `n` ресурса (для быстрого старта)
2. Вставить proxy или proxies как "текст" и создать таблицу с их данными
3. Вставить proxy file и создать таблицу с их данными

## Возможности `minor`:

1. Отображение статуса ссылки
2. Выбор статуса ссылки (работает/нет)
